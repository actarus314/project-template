# Workspace — <project>

Everything personal. **A separate git repo, LOCAL: NO remote, and it must never gain one.**
It is the project's memory — without git, a deletion here is irreversible.

- `docs/`      : living docs — `SUIVI.md` (the HOT one: cold-start resumption, it POINTS; also carries "what remains") · `archives/<stage>/` (the COLD one: one **synthesis** per closed stage — what/how/why)
                 The log **breathes**: it grows during a stage, shrinks at its closure (prune + synthesize into `archives/`, never a dump).
                 **One file, until it stops answering *"what next"* at a glance.** Past that, the **settled** and what **bites** move out beside it (`ACQUIS.md`, `PIEGES.md`), re-read at closure. 🔴 Nothing outside it calls for a gesture, or it is a second backlog.
                 ⚠️ **ADRs are NOT here** — versioned in `repo/docs/adr/` (immutable, public).
- `plans/`     : execution plans, roadmap
- `notes/`     : scratch, drafts, captures
- `secrets.md` : auth procedures, API keys, expiries — **NEVER commit**
