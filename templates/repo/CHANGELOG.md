# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Each released version links to its GitHub Release, which carries the auto-generated notes (the full list of merged pull requests). This file is the curated, human-readable counterpart:
it states what changed for a user of the project, not what was merged.
